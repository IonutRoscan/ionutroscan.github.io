Clank Lorebook Importer

✦ ready!

Browser extension · Brave / Chromium · Manifest V3

Automates lorebook entry ingestion on Clank.world. Bypasses the site's reactive input barriers by piping text directly through the Chrome DevTools Protocol instead of simulating keystrokes.

Accepted payload format 
Title: [Entry Name]
Keywords: [tag1, tag2]
Content: [Lore description...]
  • manifest.json — Manifest V3, CDP debugger permission
  • background.js — dispatches Input.insertText streams
  • content.js — DOM automation, drop-zone parser & sequencer
