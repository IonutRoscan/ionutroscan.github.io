Folio IV · Inner Mechanics

Arcane Architecture

Bypassing Reactive State Barriers:

Modern reactive frameworks often swallow synthetic JavaScript input dispatches. To overcome this seal, this artifact binds directly to the Chrome DevTools Protocol (CDP) via chrome.debugger, mimicking true OS-level keystrokes.

Supported Lorebook Format (.md): 
Title: [Entry Name]
Keywords: [tag1, tag2]
Content: [Lore description...]

Core Components:

  • manifest.json: Manifest V3 with debugger authorization.
  • background.js: Manages CDP binding & Input.insertText streams.
  • content.js: Text parsing, DOM queries, & automated entry looping.
