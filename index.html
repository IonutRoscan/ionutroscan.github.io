PRIMARY ARTIFACT

Clank Lorebook Importer

Browser Extension · Brave / Chromium · by SaltSaaalt

Forged to automate lorebook ingestion on Clank.world. Bypasses reactive state barriers by piping raw input via the Chrome DevTools Protocol (chrome.debugger).

Invocation Protocol:
Download .ZIP → Extract → brave://extensions → "Load unpacked"
⚔ Equip Artifact (.ZIP)
Accepted Text Payload (.md / .txt): 
Title: [Entry Name]
Keywords: [tag1, tag2]
Content: [Lore description...]

Architecture:

  • manifest.json: Manifest V3 with CDP debugger permissions.
  • background.js: Dispatches OS-level Input.insertText streams.
  • content.js: DOM automation, drop-zone parser & sequencer.
